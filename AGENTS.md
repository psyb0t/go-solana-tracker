# go-solana-tracker

Unofficial Go client for the Solana Tracker Data API and Datastream WebSocket API. For agent usage, read [.agents/skills/go-solana-tracker/SKILL.md](.agents/skills/go-solana-tracker/SKILL.md); this file is about changing the code.

## Architecture

Two generated packages, driven by their own `gen.go` files and discovered by `go generate ./...`:

- REST: `scripts/fetch-spec.sh` downloads `https://docs.solanatracker.io/data-api/openapi.json` to `api/openapi.json`. `scripts/patch-spec.sh` writes `api/openapi.fixed.json`, downconverting nullable type lists and the mixed integer/string cursor to OpenAPI 3.0.3. oapi-codegen uses `config.yaml` to write `client.gen.go` in package `solanatracker`.
- WebSocket: `ws/gen.go` downloads `https://docs.solanatracker.io/datastream/asyncapi.json`. `scripts/patch-asyncapi.sh` writes `api/asyncapi.client.json`, normalizing the server specification for client generation. gen-asyncapi uses `ws/config.yaml` to write `ws/solanatrackerws.gen.go` in package `solanatrackerws`.

## Stack

- Go 1.26.9.
- oapi-codegen and gen-asyncapi, pinned as `tool` dependencies in `go.mod`.
- REST runtime: `github.com/oapi-codegen/runtime`.
- WebSocket runtime: `github.com/psyb0t/gen-asyncapi/asyncapirt`.

## Layout

- `gen.go`, `config.yaml`, `client.gen.go`: REST package.
- `client_test.go`, `example_test.go`: REST tests and README example.
- `ws/`: WebSocket generator declaration, configuration, generated client and message decoding tests.
- `ws/testdata/`: schema-shaped WebSocket frames for offline tests.
- `scripts/`: spec download, spec normalization, lint and security scan scripts.
- `api/`: downloaded and patched specs, gitignored.
- `vendor/`: committed, regenerated by `make dep`.

## Dev workflow

Everything runs in the `Dockerfile.dev` image. You need Docker and Make.

```bash
make dep       # go mod tidy + go mod vendor
make generate  # download the spec and regenerate
make lint      # shellcheck, shfmt, go fix, golangci-lint
make test      # go test -race
make sec       # gitleaks, govulncheck, semgrep
```

## Project-specific landmines

- REST authentication uses the `x-api-key` header at `https://data.solanatracker.io`.
- Datastream authentication puts the key in `wss://datastream.solanatracker.io/{apiKey}`. Never log the connection URL. Datastream requires a Premium, Business or Enterprise plan.
- OpenAPI 3.1 type arrays need downconversion before oapi-codegen. Preserve both integer and string trade cursors.
- Keep the `number` to `float64` mapping in `config.yaml`.
- REST operation IDs are absent. Generated method names follow HTTP methods and paths.
- The AsyncAPI source describes the server and defines messages inline. The patch swaps operation directions, hoists messages, copies room constraints into envelopes, requires `type` and `room`, shares identical price message components and adds receive operations for joined acknowledgements.
- `BalanceUpdate.amount` is declared integer but has fractional values in the provider's examples. The AsyncAPI patch makes it `number`, generated as `float64`, so integer and fractional values both decode.
- DCA union variants have no required fields in the source. The patch requires event names on named events and the position snapshot's `pubkey` and `writeVersion`, matching the provider's examples, so decoding selects one variant.
- Generate all 43 Datastream channels. Do not add the unrelated solana-rpc or raptor specs.
- `make generate` downloads current specs. Inspect generated changes even when no local generator source changed. Remote synchronization does not delete local stale outputs; remove them explicitly after checking their contents.
- `.github/workflows/regen.yml` regenerates the client every day and releases the result. When the checks fail, Claude edits the repository to fix them, but a fix may not touch the paths listed under `fix_protected_paths` in that workflow: the workflows, the Makefile, `AGENTS.md`, `.agents/rules/`, the lint, security and spec download scripts and their configs. A problem that needs a change there fails the run and needs a manual fix.
